# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-03-01

### Added
- **Voice Engine**: Hybrid Apple Speech Recognition + Faster Whisper fallback (<200ms latency)
- **AI Brain**: Local LLM via Ollama (Llama 3.2) with cloud fallback (Groq, OpenRouter)
- **Architect Mode**: Full project scaffolding from voice commands
- **Mimic**: Macro recording and playback system
- **Content Assassin**: YouTube subtitle extraction and summarization
- **Dead Drop**: Secure ephemeral file transfer with QR codes
- **Cursor Control**: Hand gesture mouse control via webcam (MediaPipe)
- **System Control**: Volume, brightness, app management, media playback
- **Productivity**: Alarms, reminders, calendar, email, contacts integration
- **Utilities**: Calculator, weather, news, translator, web search
- **FaceID**: Local biometric authentication via face_recognition
- **Proximity Lock**: Bluetooth-based auto-lock security
- **Swift macOS App**: Native desktop client with socket-based communication
- **Modular Skill System**: Plug-and-play architecture for easy extension
- **CI Pipeline**: GitHub Actions with Python compile and import verification
